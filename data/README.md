# Game data

The server loads these files at startup with `internal/data`. They are
generated; do not edit them by hand.

| File | Content |
|---|---|
| `players/templates.json` | The 9 starting classes: class ID and name, race, base stats, level 1 HP/MP/CP, creation points |
| `players/initial_equipment.json` | Items each starting class receives, and whether they are equipped |
| `items/items.json` | ID, name, type and body part of the items used above |

The JSON schema is defined by the types in `internal/data`.

## Source and license

The files are generated by `cmd/datagen` from the L2J Mobius Interlude
datapack (`L2J_Mobius_CT_0_Interlude`):

- `dist/game/data/stats/players/templates/StartingClass/*.xml`
- `dist/game/data/stats/players/classList.xml`
- `dist/game/data/stats/players/initialEquipment.xml`
- `dist/game/data/stats/items/*.xml`
- The race of each class, which Mobius defines in code:
  `java/org/l2jmobius/gameserver/entity/actor/enums/player/PlayerClass.java`
  and `.../enums/creature/Race.java`

L2J Mobius source files are licensed under MIT or GPLv3, as stated in each
file header. Its XML data files carry no header; they describe functional
game values (stats, coordinates, item IDs and names) that the Lineage II
client expects. L2Go is licensed under GPLv3.

## Regenerating

Clone L2J Mobius into `L2J_Mobius/` (it is ignored by git), then run from the
repository root:

```sh
go run ./cmd/datagen -mobius L2J_Mobius/L2J_Mobius_CT_0_Interlude -out data
```

The output is sorted by ID and does not depend on the time or file order, so
running it again on the same datapack gives identical files. Commit the
result.
